# COMEROSA SERVICES

Sitio web corporativo desarrollado para presentar los servicios de COMEROSA SERVICES y facilitar el contacto con clientes potenciales mediante una experiencia clara y accesible.

🚀 Objetivo

Mejorar la presencia digital de la empresa y facilitar la captación de clientes mediante un sitio web moderno y funcional.

🧩 Características principales

- Presentación clara de servicios empresariales.
- Formularios dinámicos de contacto.
- Integración directa con WhatsApp.
- Diseño responsive para móviles y escritorio.
- Navegación optimizada y estructura organizada.

🛠️ Tecnologías utilizadas

Frontend: HTML5, CSS3, JavaScript  
Despliegue: Netlify

📦 Instalación local

# Clona el repositorio
